## 4. REST API（Sub-I :8001）

### 认证与用户

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/login` | 工号密码登录 |
| GET | `/me` | 当前用户 |
| POST | `/users/me/change-password` | 改密 |
| GET | `/me/permissions` | 权限摘要（角色、项目、可见范围） |
| GET | `/notifications/pending-changes` | 负责人待处理变更 |
| POST | `/notifications/{id}/read` | 单条已读 |
| POST | `/notifications/mark-all-read` | 全部已读 |
| GET/POST | `/users` | 列表 / 创建（admin/system_maintainer） |
| POST | `/users/sync-from-training` | 从培训同步人员（`?update_existing=`） |
| PUT | `/users/{id}` | 更新 |
| PUT | `/users/{id}/toggle` | 启用/禁用 |
| POST | `/users/{id}/reset-password` | 重置密码 |
| DELETE | `/users/{id}` | 删除 |

## 6. 改哪 / 不该改哪

| 任务 | 主要改 | 避免改 |
|------|--------|--------|
| 权限 | `permissions.py`、`main.py`、 `app.py` | 拆散 schedule 域 |
| Dataset | 新 `backend/datasets/`、`dataset_pages.py` | `instrument-training-home` |
| 排班 | `schedule_*.py` | 第五容器 |
| 资质 | `qualification_inquiry.py`、BFF | 复制培训全表到 Sub-I |
| 部署 | 根目录 compose + 脚本 | 覆盖 `*.db` |
