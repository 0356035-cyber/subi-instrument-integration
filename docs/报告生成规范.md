# 报告生成规范

> **用途：** Word/PDF/Excel 报告生成、模板、排版与结果呈现规则。  
> **何时读：** 开发或审查 Report 模块（阶段 6）时。  
> **状态：** 阶段 6 **规划规范**；实现见 [modules/报告生成.md](./modules/报告生成.md)。  
> **关联：** 分析结果见 [数据分析规范.md](./数据分析规范.md)；数据模型见 [数据模型.md](./数据模型.md)。

**更新日期：** 2026-07-06

---

## 1. 基本原则

```
Word 模板 → 占位符填充 → 结果表/图插入 → Results 文本（可先人工，后 AI 辅助润色）→ 人工审核 → 定稿归档
```

- **不由 AI 自由排版**
- **复杂 CSR 不全自动**
- 定稿须回挂为项目 Document

---

## 2. 模板管理

| 项 | 约定 |
|----|------|
| 目录 | `subi_knowledge_platform/templates/word/` |
| 版本 | 模板文件纳入 Git；生成实例不入库 |
| 类型 | 统计报告、CSR 摘要等（见 `report_type` 枚举） |

---

## 3. 生成流程（第一版）

1. 选择 `report_type` 与 Word 模板
2. 关联 `source_analysis_ids`（AnalysisTask）
3. 填充占位符（项目信息、表格数据）
4. 插入结果表（来自 `result_table_path` 或 `result_json`）
5. Results 章节：人工撰写为主，AI 仅辅助润色
6. 导出 docx → 上传为 Document（`document_type=Statistical Report` 等）

---

## 4. 报告类型（`report_type`）

- `Statistical Report` — 统计分析报告
- `Clinical Study Report` — 临床研究报告（远期）
- `Summary Report` — 摘要报告
- `Ethics Submission Document` — 伦理递交文件

---

## 5. 状态与审核

| 状态 | 含义 |
|------|------|
| 草稿 | 可重新生成 |
| 待审 | 已生成，等待负责人/主任审核 |
| 定稿 | 不可自动覆盖；新版本升 `version` |

`reviewed_by` 记录审核人；`generation_log_json` 记录填充过程。

---

## 6. 本阶段不做

- AI 全权排版与签发
- 复杂 CSR 全自动生成
- PDF 作为唯一编辑格式（docx 为主）

---

## 7. 验收标准

一份统计报告 docx 从模板生成，审核后挂回项目，权限与版本规则正确。
