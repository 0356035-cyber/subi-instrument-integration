# 数据分析规范

> **用途：** 临床研究数据处理、统计分析、结果校验规则。  
> **何时读：** 开发或审查 Dataset（阶段 4）、Analysis（阶段 5）相关功能时。  
> **状态：** 阶段 4～5 **规划规范**；实现前以本文 + [modules/数据导入-Dataset.md](./modules/数据导入-Dataset.md) + [modules/统计分析.md](./modules/统计分析.md) 为准。  
> **关联：** 数据模型见 [数据模型.md](./数据模型.md)；架构原则见 [系统总览.md](./系统总览.md)。

**更新日期：** 2026-07-06

---

## 1. 三层分离中的「规则/统计层」

| 层 | 职责 |
|----|------|
| **AI 层** | 读 Protocol/SAP、识别终点与访视、生成分析计划**草稿** |
| **规则/统计层** | 可重复计算、留痕、与 SPSS 等对照 |
| **报告层** | Word 模板填充（见 [报告生成规范.md](./报告生成规范.md)） |

**AI 不做：** 最终 P 值确认、样本剔除定稿、统计结论定稿。

## 2. Dataset 数据处理规则（阶段 4）

### 2.1 第一版能力

- 上传 Excel（脱敏数据）
- 选择 sheet、预览前 20 行
- 识别样品编号 / 访视 / 指标列（含**人工确认**）
- 保存 `Dataset` 记录与映射 JSON

### 2.2 字段映射

| JSON 字段 | 含义 |
|-----------|------|
| `detected_columns_json` | 原始列名列表 |
| `visit_mapping_json` | 访视列映射 |
| `variable_mapping_json` | 指标列映射 |

### 2.3 状态流转

`草稿` → 用户确认映射 → `已确认`（方可被 Analysis 引用）

### 2.4 本阶段不做

- 复杂数据清洗流水线
- 自动对接仪器原始文件

## 3. Analysis 统计分析规则（阶段 5）

### 3.1 执行流程

```
分析计划（可来自 AI 草稿）→ 用户确认 → 规则引擎执行 → result_json + log_json → 人工审核
```

### 3.2 第一版分析类型候选

- 使用前后配对比较（正态性 → t / Wilcoxon）
- 改变率计算
- 有效率 / 同意率（二项）
- 安全性不良反应汇总（可选）

### 3.3 留痕要求（`log_json` 必含）

- 输入数据集 ID 与版本
- 分析人群、纳入/剔除规则
- 统计方法与参数（含 `alpha`）
- Python 包名与版本
- 样本量、缺失处理
- 结构化结果与执行时间

### 3.4 与外用工具对照

- 复杂统计仍可用 **SPSS / GraphPad / R**
- 系统内标准分析须能与 SPSS 结果对照（同一脱敏试点项目）
- 外用结果可回项目归档为 Document（`document_type=Statistical Report`）

### 3.5 本阶段不做

- 全量 SAP 自动执行
- AI 直接输出最终 P 值

## 4. 数据安全

- 试点使用脱敏 Excel
- 分析任务挂 `project_id`，遵循 [modules/权限与用户管理.md](./modules/权限与用户管理.md)
- 原始数据归档为项目 Document（`document_type=Raw Data`）
