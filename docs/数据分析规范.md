# 数据分析规范

> **用途：** 临床研究数据处理、统计分析、结果校验规则。  
> **何时读：** 开发或审查 Dataset（阶段 4）、Analysis（阶段 5）相关功能时。  
> **状态：** 阶段 4～5 **规划规范**；实现前以本文 + [modules/数据导入-Dataset.md](./modules/数据导入-Dataset.md) + [modules/统计分析.md](./modules/统计分析.md) 为准。  
> **关联：** 数据模型见 [数据模型.md](./数据模型.md)；架构原则见 [系统总览.md](./系统总览.md)。

**更新日期：** 2026-07-06

---

## 1. 三层分离中的「规则/统计层」

| 层 | 职责 |
|----|------|
| **AI 层** | 读 Protocol/SAP、识别终点与访视、生成分析计划**草稿** |
| **规则/统计层** | 可重复计算、留痕、与 SPSS 等对照 |
| **报告层** | Word 模板填充（见 [报告生成规范.md](./报告生成规范.md)） |

**AI 不做：** 最终 P 值确认、样本剔除定稿、统计结论定稿。

## 2. Dataset 数据处理规则（阶段 4）

### 2.1 第一版能力

- 上传 Excel（脱敏数据）
- 选择 sheet、预览前 20 行
- 识别样品编号 / 访视 / 指标列（含**人工确认**）
- 保存 `Dataset` 记录与映射 JSON

### 2.2 字段映射

| JSON 字段 | 含义 |
|-----------|------|
| `detected_columns_json` | 原始列名列表 |
| `visit_mapping_json` | 访视列映射 |
| `variable_mapping_json` | 指标列映射 |

### 2.3 状态流转

一般数据集遵循：`草稿` → 用户确认映射 → `已确认`（方可被 Analysis 引用）。受控仪器模板生成的派生数据集在全部规则校验通过时可自动确认；存在任一异常时必须保留草稿。

### 2.4 本阶段不做

- 复杂数据清洗流水线
- 非受控仪器原始文件自动对接

### 2.5 受控仪器数据自动整理

当前仅对确认过结构的 TEWL/Corneo `.xlsx` 导出启用规则化整理：系统自动扫描已支持的 Sheet；存在 `CM825 Single` 时从原始测量计算每 3 次 Hydration 的平均值，存在 `TMHex` 时提取 `TEWL Robust [g/m²/h]`。两个 Sheet 可独立存在。`Subject` 必须拆分为项目编码、访视和受试者编号，并与当前 Project 编号校验。

自动整理不得覆盖原始文件；必须生成独立 Analysis Dataset，并记录来源数据集、模板版本、输入/输出行数与异常。任何解析、项目编号、测量次数、重复记录或数值异常均不得自动确认数据集。

含直接身份信息的人员表不得进入自动分析数据集；问卷宽表和 XML 仪器导出须在单独受控模板完成前保持原始归档。

受控的受试者信息与自我评估问卷模板可从同一或不同 Excel 文件识别：人口学派生数据仅保留匿名分析键、性别和年龄；问卷派生数据标准化访视与题目评分。原始文件中的姓名、首字母、出生日期等直接身份信息不进入派生数据集。

## 3. Analysis 统计分析规则（阶段 5）

### 3.1 执行流程

```
分析计划（可来自 AI 草稿）→ 用户确认 → 规则引擎执行 → result_json + log_json → 人工审核
```

### 3.2 第一版分析类型候选

- 使用前后配对比较（正态性 → t / Wilcoxon）
- 改变率计算
- 有效率 / 同意率（二项）
- 安全性不良反应汇总（可选）

### 3.3 留痕要求（`log_json` 必含）

- 输入数据集 ID 与版本
- 分析人群、纳入/剔除规则
- 统计方法与参数（含 `alpha`）
- Python 包名与版本
- 样本量、缺失处理
- 结构化结果与执行时间

### 3.4 结果数值展示

- 统计计算使用原始精度完成，避免展示规则影响检验方法或显著性判断。
- `result_json`、结果表和后续导出的计算结果统一按两位小数输出；P 值例外，统一按三位小数输出；页面补足相应尾随零。
- 样本量及等级资料的 `Sum`、`Min`、`Max` 保持整数；原始 Dataset 不因结果格式化而被改写。

### 3.5 常规自动前后配对分析

- 自动模式遍历全部已确认映射的常规 Dataset；只有存在 `BL` 及至少一个其他访视的数据集进入分析。`BL` 固定为基线，每个其他访视独立与 `BL` 配对。
- 所有已映射指标均纳入批量处理。名称含“临床评估”或“乳酸刺痛”的指标按等级资料处理，其他指标按连续型资料处理；两种资料分开生成任务。
- 连续型资料对配对差值执行 Shapiro 检验，随后选择配对 t 检验或 Wilcoxon 符号秩检验；等级资料固定 Wilcoxon 符号秩检验。
- 自动模式固定 `alpha=0.05`、双尾、Wilcoxon 精确 P 值，沿用 SPSS 对齐的零差值、并列秩处理。精确法通过动态规划计算，不受 20 个有效非零配对样本的固定上限限制；若状态空间或计算时限超出系统保护范围，必须提示并保留任务草稿，不得自动改用渐近法。
- 同一 Dataset、`BL` 与对比访视、资料类型和指标分组的自动任务仅创建一次；重复执行时跳过既有任务，重跑仍通过任务详情页的人工操作完成。

### 3.5.1 自我评估问卷与人口学

- 人口学汇总年龄使用 Mean±SD（1 位小数）、Min、Max（整数），性别以人数和构成比描述。
- 受控自我评估问卷自动分析按访视和题目批量执行精确二项检验：评分 4-5 为有效、1-3 为无效、理论比例为 0.67、双尾检验。
- 手动有效率/同意率分析可以修改阈值、判定规则和理论比例；自动结果不得直接形成科研结论，仍须经人工审核。

### 3.6 与外用工具对照

- 复杂统计仍可用 **SPSS / GraphPad / R**
- 系统内标准分析须能与 SPSS 结果对照（同一脱敏试点项目）
- 外用结果可回项目归档为 Document（`document_type=Statistical Report`）

### 3.7 本阶段不做

- 全量 SAP 自动执行
- AI 直接输出最终 P 值

- 分析任务挂 `project_id`，遵循 [modules/权限与用户管理.md](./modules/权限与用户管理.md)
