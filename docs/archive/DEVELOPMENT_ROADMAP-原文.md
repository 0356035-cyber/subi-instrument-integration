## 阶段 5：Analysis 统计分析模块

### 目标

实现 **2～3 种最常用标准分析**；与 SPSS 结果可对照；全程留痕。

### 候选分析类型

- 使用前后配对比较
- 改变率计算
- 有效率 / 同意率
- 安全性不良反应汇总（可选）

### 流程

```
分析计划（可来自阶段 7 草稿）→ 用户确认 → 规则引擎执行 → result_json + log_json
```

### 规划落点

`backend/analysis/`、`frontend/analysis_pages.py`

### 不做（本阶段）

- 全量 SAP 自动执行
- AI 直接给出最终 P 值

### 验收

- 选定 1 个真实项目 + Dataset，跑通 1 种分析并导出结果表

## 阶段 7：AI Workspace

### 目标

AI **理解**项目资料，输出建议，**不自动执行**统计。

### 第一版 AI 任务

- [ ] 读取 Protocol / SAP（已上传 Document）
- [ ] 提取研究设计、终点、访视、统计方法
- [ ] 生成分析计划草稿
- [ ] 「问这个项目」基础问答（脱敏、留痕）

### 规划落点

`backend/ai_workspace/`、`frontend/ai_workspace.py`

### 约束

- 不直连数据库写结论
- `ai_action_logs` 记录参考了哪些文档

### 验收

- 项目 AI 页展示解析状态 + 可审阅的分析计划草稿
