# 整合与部署

> **用途：** Docker Compose、三仓库、备份恢复、离线包与极空间部署要点。  
> **何时读：** 启动系统、换机、NAS 部署、备份恢复时。  
> **关联：** 系统架构见 [系统总览.md](../系统总览.md)；历史逐步操作见 [archive/极空间部署说明-原文.md](../archive/极空间部署说明-原文.md)。

## 三仓库布局

```
C:\projects\                          ← subi-instrument-integration
├── docker-compose.yml
├── docker-compose.tunnel.yml         ← Cloudflare Tunnel（可选）
├── docker-compose.zspace.yml         ← 极空间覆盖（可选）
├── start-docker.bat / 启动系统.bat
├── 备份数据.bat / 恢复数据.bat
├── subi_knowledge_platform\
└── instrument-training-home\
```

克隆：

```bash
git clone https://github.com/0356035-cyber/subi-instrument-integration.git projects
cd projects
git clone https://github.com/0356035-cyber/subi_knowledge_platform.git
git clone https://github.com/0356035-cyber/instrument-training-home.git
```

## 数据路径（不提交 Git）

| 数据 | 路径 |
|------|------|
| 培训库 | `instrument-training-home/data/instrument_training.db` |
| Sub-I 库 | `subi_knowledge_platform/data/subi_knowledge.db` |
| 附件 | `subi_knowledge_platform/uploads/` |
| Tunnel Token | `.env.tunnel` |

**同步原则：** 代码 `git pull`；业务数据 `备份数据.bat` → 拷贝 `backups/` → `恢复数据.bat`

## 新电脑首次搭建

1. 安装 Docker Desktop
2. 克隆三仓库
3. 复制 `subi_knowledge_platform/.env.example` → `.env` 并填写培训服务账号
4. 有备份则 `恢复数据.bat`
5. `start-docker.bat`

## 极空间 NAS + Cloudflare Tunnel

- 内网示例：`http://<NAS_IP>:8501`、`http://<NAS_IP>:8510`
- 外网：`https://train.域名`、`https://subi.域名`
- Token：`cp .env.tunnel.example .env.tunnel`
- 启动：`启动Tunnel.bat`

极空间通常**无 git**：从家里拷贝变更代码 → SSH `docker compose build` → `up -d`。**勿覆盖 data/。**

API 8000/8001 **不暴露**到外网。

详细步骤与故障排查见 archive 中极空间文档。
