# 工作日志与月报

> **用途：** 每日工作实绩、个人月报汇总与周末加班手填。  
> **何时读：** 改每日记录、月报生成或周排班拉取逻辑时。  
> **状态：** 第一期已实现；待页面人工验证。Word 导出未开始。  
> **关联：** 周排班见 [排班与项目日历.md](./排班与项目日历.md)。这不是临床研究 Report 模块。

---

## 目标

把周排班里的计划工作带入每日记录，由本人手填完成情况/数量；生成个人月报时，将同一项目且工作内容相同的记录收成一行。

月报栏目对齐现有 Word 工作月报表：本月总结、下月计划、存在问题、平时加班统计。

---

## 规则

- 拉取来源：本人已保存的周排班。跳过空格子、休息、调休、年假、待定、休假。
- 同一天、同一项目、相同工作内容（含上下午）收成一条日记录。
- 工作量只手填；再次拉取不覆盖已填工作量，只提示计划有更新。
- 周排班没有的事项可手动补行。
- 月报按 `(project_id, 工作内容)` 合并；无项目则按工作内容合并。
- 生成月报只刷新本月总结；下月计划、存在问题、加班保留已有手写。
- 下月计划可从下个月已保存且已关联项目/日历的周排班，以及已排到本人的项目日历事项导入；相同内容不重复写入，导入后仍可手改。
- 加班仅手填周末组员加班，不自动从排班计算。
- 记录与月报都只属于当前登录人。
