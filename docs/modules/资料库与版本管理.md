# 资料库与版本管理

> **用途：** 通用资料库、版本组、对比、上传与权限可见性。  
> **何时读：** 改资料相关 UI/API 时。  
> **关联：** 权限见 [权限与用户管理.md](./权限与用户管理.md)；代码见 [代码地图.md](../代码地图.md) §资料 API。

---

## 核心能力

- 首页分类、资料列表、上传/编辑/删除、附件下载与受控预览（PDF 页面预览，DOCX/TXT 正文预览）
- 首页「最新通告」入口：展示通用资料中分类为「部门内部要求」且带有「通知通告」标签的内容
- **版本组** `document_group_id`（不再依赖标题完全一致）
- 历史版本查看/下载、元数据+正文左右对比
- 生效日期 `date_input` 统一校验；按生效日自动刷新现行/废止状态
- `document_type`：Protocol / SAP / CRF / Raw Data / Statistical Report 等

## 版本规则

- 同 `document_group_id` = 同一资料的不同版本
- **当前版本** = `effective_date` 最晚（相同则 `id` 更大）
- 列表展示前先合并为最新版；历史版本仅在详情时间线显示
- 上传新版本后调用 `refresh_version_status_by_effective_date`

## 与项目的关系

- `project_id` 可空：空 = 通用资料库
- 项目资料 Tab 筛选挂项目的 Document；从项目 Tab 进入时使用专用上传模式，所属项目固定，分类由系统写为「项目资料」
- 「项目资料」不能作为通用资料上传；项目内以 `document_type`（Protocol、SAP、CRF、伦理批件等）作为实际归档与筛选维度
- 通用上传入口只用于法规、模板、培训课件等资料；首页及资料列表默认展示通用资料，项目资料在项目详情或选择对应项目范围后查看
- 项目成员对项目资料**只读**；负责人可编辑

## 部门内部要求

分类「部门内部要求」须设 `audience_scope`：

| 值 | 含义 |
|----|------|
| `all_staff` | 全员须知 |
| `project_leads_only` | 项目负责人须知 |

仅 `schedule_manager` / `admin` 可发布并设定标识。

## 最新通告

分类「最新通告」是独立的部门通告栏：首页单独展示最近更新内容，且不混入「部门内部要求」。通告不能关联具体项目，所有登录用户可查看。

仅科室主任（`schedule_manager`）及江文才（工号 `3223`）可发布、编辑、删除。

最新通告不使用额外标签或 `audience_scope` 筛选；首页单独展示最近通告，通告页展示该分类的完整列表。
