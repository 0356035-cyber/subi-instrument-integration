# 项目管理

> **用途：** 项目台账、详情 8 Tab、`document_type`、相似项目推荐。  
> **何时读：** 改项目列表/详情/资料挂项目时。  
> **关联：** 排期见 [排班与项目日历.md](./排班与项目日历.md)；权限见 [权限与用户管理.md](./权限与用户管理.md)。

---

## 一期能力

- 项目 CRUD、标签筛选、相似项目推荐
- 资料挂 `project_id`（上传/编辑/列表筛选）
- 项目详情 **8 Tab** 信息架构

---

## 项目详情 Tab

```
概览 | 资料 | 排期 | 人员资质 | 数据集 | 分析 | 报告 | AI 工作区
```

| Tab | 状态 | 实现 |
|-----|------|------|
| 概览 | ✅ | 基本信息、模块状态、相似项目 |
| 资料 | ✅ | 项目 Document 列表 + 上传 |
| 排期 | ✅ | `schedule_calendar.show_project_visit_tab` |
| 人员资质 | ✅ | `qualification_inquiry` 嵌入面板 |
| 成员 | ✅ | 项目成员 Tab（`ProjectMember`） |
| 数据集/分析/报告/AI | 🔲 | 占位，链到对应 tasks |

---

## 关键文件

| 文件 | 职责 |
|------|------|
| `frontend/project_management.py` | 列表、新建、详情 Tab |
| `backend/crud.py` | 项目 CRUD |
| `backend/project_migrations.py` | 项目表 DDL |

---

## Project 核心字段

- `owner_employee_id` — 项目负责人（驱动编辑权限）
- `baseline_date` — 基线日（日历同步）
- `status` / `tags` / `claim_type` / `ethics_type`

---

## document_type

上传/编辑时可指定，用于 AI 与报告模块识别资料类型。枚举见 [数据模型.md](../数据模型.md) §Document。
