# 项目管理

> **用途：** 项目台账、详情 10 Tab、`document_type`、测试环节与相似项目推荐。
> **何时读：** 改项目列表/详情/资料挂项目时。  
> **关联：** 排期见 [排班与项目日历.md](./排班与项目日历.md)；权限见 [权限与用户管理.md](./权限与用户管理.md)。

---

## 一期能力

- 项目 CRUD、标签筛选、相似项目推荐
- 项目成员从启用中的系统用户多选；负责人不在成员列表中
- 资料挂 `project_id`（上传/编辑/列表筛选）
- 项目详情 **10 Tab** 信息架构
- 测试环节可按临床评估、仪器检测、乳酸试验、自评问卷、产品使用、筛选问卷等类型登记；每条环节指定一名项目工作人员负责

---

## 项目详情 Tab

```
概览 | 资料 | 排期 | 测试环节 | 人员资质 | 成员 | 数据集 | 分析 | 报告 | AI 工作区
```

| Tab | 状态 | 实现 |
|-----|------|------|
| 概览 | ✅ | 基本信息、模块状态、相似项目 |
| 资料 | ✅ | 项目 Document 列表 + 上传 |
| 排期 | ✅ | `schedule_calendar.show_project_visit_tab`；同步时可选择上午、下午或上午和下午 |
| 测试环节 | ✅ | `project_test_stages.show_project_test_stages_tab`；环节与一名项目工作人员对应，记录计划、状态与完成信息 |
| 人员资质 | ✅ | `qualification_inquiry` 嵌入面板 |
| 成员 | ✅ | 项目成员 Tab（`ProjectMember`） |
| 数据集/分析/报告/AI | 🔲 | 占位，链到对应 tasks |

## Project 核心字段

- `owner_employee_id` — 项目负责人（驱动编辑权限）
- `baseline_date` — 基线日（日历同步）
- `status` / `tags` / `claim_type` / `ethics_type`

## 测试环节与人员

- 测试环节属于项目，负责人必须为该项目负责人或已加入项目的成员；同一工作人员可以负责多个环节。
- 当前不保存仪器信息；未来仪器管理模块准备好后，在 `ProjectTestStage` 上以独立关联扩展，保持 Sub-I 不直接写入培训系统数据库的边界。
