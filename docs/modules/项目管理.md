# 项目管理

> **用途：** 项目台账、详情 8 Tab、`document_type`、相似项目推荐。  
> **何时读：** 改项目列表/详情/资料挂项目时。  
> **关联：** 排期见 [排班与项目日历.md](./排班与项目日历.md)；权限见 [权限与用户管理.md](./权限与用户管理.md)。

---

## 一期能力

- 项目 CRUD、标签筛选、相似项目推荐
- 临床研究项目汇总：编号、名称、公司、负责人、起止时间、状况、报告、备注九列台账（仅全盘项目权限用户）
- 项目成员从启用中的系统用户多选；负责人不在成员列表中
- 资料挂 `project_id`（上传/编辑/列表筛选）
- 项目详情 **8 Tab** 信息架构

## Project 核心字段

- `owner_employee_id` — 项目负责人（驱动编辑权限）
- `baseline_date` — 基线日（日历同步）
- `status` / `tags` / `claim_type` / `ethics_type`
- `claim_type` 使用逗号分隔保存多项功效；界面支持选择建议功效并手动补充相关功效
- `ethics_type` 可选值为“需要伦理审查”“免伦理”“不适用”

## 临床研究项目汇总

- 入口位于「项目管理」页面，仅 `admin` / `schedule_manager` 可见；江文才（工号 `3223`、`admin`）登录后可访问。
- 开始时间优先使用 `baseline_date`，否则使用首个项目日历事件；结束时间使用最后一个项目日历事件。
- 报告列使用人工维护的项目报告进展：未启动、已完成草稿、已发申办方审核、已完成正式报告；备注使用项目摘要。该字段不是 Report 模块，也不代表已生成或归档正式报告。
- 新建或更新时，如填写负责人，系统校验其工号对应的用户存在且启用；如填写基线日，必须为有效的 `YYYY-MM-DD` 日期。项目状态与报告进展存在潜在不一致时仅提示人工确认，不自动改变状态。
