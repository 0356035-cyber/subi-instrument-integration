# 仪器培训系统

> **用途：** `instrument-training-home` 独立系统功能与整合 API。  
> **何时读：** 改培训/考核/授权、整合端点时。  
> **关联：** Sub-I 侧见 [资质整合.md](./资质整合.md)。

---

## 定位

**保持独立，不并入 Sub-I。** 负责人员台账、仪器台账、培训/考核/授权、到期提醒、Excel 导入。

技术栈：Streamlit (:8501) + FastAPI (:8000) + SQLite

---

## 主要功能

| 模块 | 说明 |
|------|------|
| 人员管理 | 科室人员；`can_login` 白名单 |
| 仪器管理 | 台账、重复仪器合并 |
| 培训/考核/授权 | ID 按业务日期重排；多次授权取最新授权日生效 |
| 人员综合查询 | 培训/考核/授权总表 |
| 到期提醒、操作日志、统计报表 | 日常管理 |
| Excel 导入 | 批量导入实验室 Excel |

---

## 登录白名单

仅配置名单内人员可登录（`instrument-training-home/app/config.py` → `login_allowed_names`）。科室可登记多人，登录权单独控制。

---

## 整合 API（供 Sub-I）

前缀 `/api/v1`：

| 路径 | 说明 |
|------|------|
| `GET /integrations/qualifications` | 按工号查资质 |
| `GET /integrations/qualifications/by-instrument` | 按仪器查 |
| `GET /users/by-employee-id/{employee_id}` | 按工号查用户 |
| `GET /health` | 健康检查 |
