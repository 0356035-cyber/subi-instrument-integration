# 排班与项目日历

> **用途：** 访视节点、项目日历、周排班、冲突预警、资质联动。  
> **何时读：** 改排班/日历相关功能时。  
> **关联：** 项目 Tab 见 [项目管理.md](./项目管理.md)；代码见 [代码地图.md](../代码地图.md) §排班 API。

**状态：** 阶段 0～2 已上线

---

## 能力清单

- 访视模板与项目访视节点
- 基线日 → 自动生成日历事件（`calendar/sync`）；可选择上午、下午或上午和下午
- 周排班：上下午分栏、草稿续填、Excel 导出、科室汇总
- 周末预填下周、下周未填提醒
- 项目人员冲突预警、仪器岗资质提示
- 周排班与项目日历关联（按日/时段）

## 权限

- 项目日历：所有已登录用户可查看全部项目的日历事项。
- 项目成员：可查看所属项目的访视节点与项目详情排期。
- 项目负责人：可新增、编辑和删除所负责项目的日历事项。
- `schedule_manager` / `admin`：可编辑全部项目的日历事项。
- 手动新增的日历事项必须关联一个可编辑项目；不再新增未关联项目的通用事项。
- 既有未关联项目的历史事项保留展示，但仅可查看，不能编辑或删除。
