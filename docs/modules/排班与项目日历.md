# 排班与项目日历

> **用途：** 访视节点、项目日历、周排班、冲突预警、资质联动。  
> **何时读：** 改排班/日历相关功能时。  
> **关联：** 项目 Tab 见 [项目管理.md](./项目管理.md)；代码见 [代码地图.md](../代码地图.md) §排班 API。

**状态：** 阶段 0～2 已上线

---

## 能力清单

- 访视模板与项目访视节点
- 基线日 → 自动生成日历事件（`calendar/sync`）；可选择上午、下午或上午和下午
- 周排班：上下午分栏、草稿续填、Excel 导出、科室汇总
- 周末预填下周、下周未填提醒
- 项目人员冲突预警、仪器岗资质提示
- 周排班与项目日历关联（按日/时段）

## 周排班汇总

- 汇总页固定列出归属包含 `临床研究部` 或 `受试库` 的全部在职人员；员工可同时归属多个标准部门。
- 员工提交周排班后，在对应日期与时段显示内容；未提交的人员仍保留姓名行，排班单元格为空。
- 汇总导出的 Excel 与页面使用同一人员清单，便于识别尚未提交排班的人员。
- 汇总接口仅供具有全盘业务查看权限的用户使用；个人排班接口保持原有行为。
