# 框架整理与加固-第一轮

> **状态：** 进行中  
> **类型：** 框架维护 / 文档同步 / 配置卫生  
> **边界：** 不开发新功能，不修改业务逻辑，不修改数据库结构，不触碰业务数据、附件或真实配置。

---

## 背景

当前项目已形成根目录整合仓 + 两个独立子系统 + docs 文档体系。为便于长期交给 Codex 协助维护，本轮只做低风险整理：同步入口文档、明确脚本风险、标注测试风险、清理明显损坏的忽略规则。

---

## 修改范围

允许修改：

- `README_FOR_CODEX.md`
- `docs/modules/整合与部署.md`
- `docs/开发规范.md`
- `docs/代码地图.md`
- `instrument-training-home/.gitignore`
- `AGENTS.md`
- `docs/tasks/框架整理与加固-第一轮.md`

禁止修改：

- `data/`
- `uploads/`
- `backups/`
- `.env` / `.env.tunnel`
- SQLite `.db` 文件
- `docker-compose*.yml`
- 启动、备份、恢复脚本
- Sub-I 或培训系统业务代码
- 数据库迁移逻辑

---

## 风险控制

- 不运行 Docker。
- 不启动服务。
- 不运行 pytest。
- 不运行任何冒烟脚本。
- 不处理 Git `safe.directory`。
- 不提交 Git。
- 仅做只读验证：查看文件内容、检查 `.gitignore` 尾部、查看 `git status --short`。
