# 开发任务记录

> **用途：** 记录具体开发任务的背景、文件、进度与注意事项。  
> **何时读：** 承接或完成某项开发任务时。  
> **更新义务：** 任务状态变化时同步更新本目录对应文件及 [PROJECT_STATUS.md](../../PROJECT_STATUS.md)。

---

## 任务文档模板

每个任务文件应包含：

1. **背景** — 为什么做
2. **涉及文件** — 主要改动路径
3. **修改目标** — 验收标准
4. **已完成** — 勾选清单
5. **未完成** — 待办
6. **注意事项** — 坑与约束
