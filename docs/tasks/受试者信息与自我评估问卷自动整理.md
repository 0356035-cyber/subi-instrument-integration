# 任务：受试者信息与自我评估问卷自动整理

> **状态：** 代码实现完成，待重建后的页面验证
> **范围：** Project 内 Dataset 与 Analysis 的受控扩展，不新增数据库实体。

## 输入与隐私边界

- 识别受试者信息表（筛选编号、性别、年龄）和自我评估问卷表（研究号、访视、题目评分）。
- 两类数据可以在同一工作簿，或拆分为不同 Excel 分别上传。
- 原始文件保留为来源；派生数据集不写入姓名、首字母、出生日期等直接身份信息。

## 派生数据集

- 人口学：`subject_id`、`sex`、`age`。
- 问卷：`subject_id`、`visit_code`、题目评分；`15分钟`、`2周`、`4周` 标准化为 `15MIN`、`D14`、`D28`。
- 水分、TEWL、人口学和问卷均可来自多份原始文件；每个派生数据集保留来源数据集 ID 与处理日志。

## 自动分析规则

- 人口学：年龄 Mean±SD（1 位小数）、Min、Max（整数）；性别人数和构成比。
- 自我评估问卷：4-5 分为有效，1-3 分为无效；理论比例 0.67；双尾精确二项检验。
- 问卷任务按访视批量执行，结果记录 N、有效/无效数、有效率、95% CI 与 P 值。
- 所有结果通过既有 AnalysisTask 执行、重跑、审核和审计留痕，不自动形成科研结论。

## 验证

- 拆分工作簿识别与隐藏行读取：隔离测试通过。
- 真实项目工作簿只读解析：识别到人口学 118 行，问卷 66 行，访视为 `15MIN`、`D14`，无格式异常。
