# 任务：Analysis 模块 V2 第三阶段

> 状态：代码已完成，待手动页面验证
>
> 目标：支持单组自身前后对照的资料类型选择、等级资料统计描述与多指标批量配对分析。

## 已实现

- 配对比较可选择连续型计量资料或等级资料。
- 连续型资料：Mean、SD 保留两位小数；先进行 Shapiro 检验，再选择配对 t 检验或 Wilcoxon 符号秩检验。
- 等级资料：输出 `n`、Sum、Min、Median、Max；固定使用 Wilcoxon 符号秩检验，跳过正态性检验。
- `α` 固定为 `0.05`，双尾检验；Wilcoxon 可选择渐近或精确 P 值。精确法对零差值或并列秩使用穷举置换，对超过 20 个有效非零配对样本明确拒绝执行，固定 SPSS 对照配置并记录于结果和日志。
- 配对比较支持一次选择多个指标，生成汇总表与逐指标明细；不进行多重比较校正，也不生成自动临床结论。
- `change_rate` 继续保持单指标连续型分析。

## 不在范围内

- 试验组与对照组的组间比较、多组比较和多重比较校正。
- 问卷二项分布检验。
- VISIA、OCT、PRIMOS 等专用仪器数据分析。
- 数据库迁移或新增数据实体。
