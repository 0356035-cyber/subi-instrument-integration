# 工作日志与月报

## 背景

现有周排班只记录计划，项目日历只记录项目节点，临床 Report 是功效评价报告。科室个人月报需要每日实绩和按月汇总，对应既有 Word「工作月报表」四段：本月总结、下月计划、存在问题、平时加班统计。

## 涉及文件

- `subi_knowledge_platform/backend/worklogs/`
- `subi_knowledge_platform/backend/models.py`
- `subi_knowledge_platform/backend/main.py`
- `subi_knowledge_platform/frontend/worklog_pages.py`
- `subi_knowledge_platform/frontend/app.py`
- `subi_knowledge_platform/backend/tests/test_worklogs.py`
- `docs/modules/工作日志与月报.md`

## 修改目标

1. 可从周排班拉取当天/本周工作内容
2. 工作量手填，已填不被覆盖
3. 生成个人月报时按项目+工作内容合并
4. 下月计划、问题、周末组员加班可手写保存
